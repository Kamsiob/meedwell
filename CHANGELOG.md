# Changelog

User-facing release notes, in plain language. What changed for the person using the app, never commit messages and never internal refactor names. One section per released version, newest first.

Rules for entries here:

- Write what a user would notice. "The queue now survives a restart" rather than "persisted queue state to Room".
- No em dashes, anywhere, per the standing rule.
- Never claim a capability that verification has not confirmed.
- Never state or imply that the Play build and the GitHub build are signed differently, because they are not.
- A version appears here only once it is actually released.
